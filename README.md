# Автономный фронтенд ECM Systems для GitHub Pages

В этой папке подготовлена **100% автономная версия** сайта и чат-виджета ECM Systems, предназначенная для публикации на **GitHub Pages** (`https://<username>.github.io/<repo>/`).

Она работает **напрямую в браузере клиента**, не требует запущенного Python-бэкенда, `localhost`, `ngrok` или `cloudflared`.

---

## ⚡️ Возможности автономной версии (`gh-pages/widget.js`)

1. **Прямое подключение к Google Gemini REST API**:
   - Запросы отправляются напрямую в модели `gemini-2.5-flash` / `gemini-1.5-flash` через официальный HTTPS-эндпоинт Google.
   - История переписки сохраняется в `localStorage` браузера (`ecm_msgs_default`).
2. **Встроенная экспертная база детейлинга**:
   - Прайс-лист по классам кузовов (Седан, Кроссовер, Джип/Внедорожник).
   - Логика **Умного Допродажника (Upsell)**: при вопросе о полировке ИИ нативно рекомендует закрыть результат керамикой 9H, дарит антидождь по акции и подбирает свободные окна в расписании.
3. **Smart Scenario Fallback (Работа без VPN в РФ)**:
   - Если у пользователя в РФ заблокирован прямой доступ к API Google или нет VPN, виджет **не ломается**, а мгновенно переключается на встроенный интеллектуальный сценарий: рассчитывает кузов, допродает сопутствующие услуги, проверяет свободные слоты и фиксирует номер телефона.
4. **Защита от скликивания**:
   - Для демо-режима установлен лимит 15 сообщений на сессию.

## 🔑 Управление API-ключом Gemini

Вы можете использовать виджет 3 способами:

1. **Через URL-ссылку для клиента / инвестора (Самый удобный способ):**
   ```text
   https://<username>.github.io/<repo>/?key=ВАШ_API_КЛЮЧ_GEMINI
   ```
   *Ключ автоматически запишется в `localStorage` браузера (`ecm_gemini_key`). При последующих переходах и обновлениях страницы параметр `?key=` указывать уже не нужно!*

2. **Через атрибут тега `<script>` в HTML:**
   ```html
   <script src="./widget.js" data-studio="default" data-key="ВАШ_API_КЛЮЧ"></script>
   ```

3. **Без указания ключа:**
   Виджет автоматически использует встроенный демо-ключ проекта с защитным лимитом либо автономный сценарий.

## 🚀 Пошаговая инструкция по публикации в GitHub

### Вариант 1. Отдельный чистый репозиторий (Рекомендуется)

Создайте на GitHub репозиторий (например, `ecm-showcase` или `ecmsystems.github.io`) и выполните в терминале на MacBook:

```bash
# 1. Перейдите в папку gh-pages
cd /Users/maxim/Desktop/ecm1/gh-pages

# 2. Инициализируйте чистый git-репозиторий
git init
git add .
git commit -m "Deploy autonomous ECM Systems widget to GitHub Pages"

# 3. Переименуйте ветку в main
git branch -M main

# 4. Привяжите ваш GitHub-репозиторий (замените на свой URL)
git remote add origin https://github.com/<ВАШ_АККАУНТ>/<ИМЯ_РЕПОЗИТОРИЯ>.git

# 5. Отправьте файлы на GitHub
git push -u origin main --force
```

### Вариант 2. Публикация из общего репозитория через ветку `gh-pages`

Если весь проект `ecm1` уже привязан к удалённому репозиторию:

```bash
cd /Users/maxim/Desktop/ecm1
git add gh-pages
git commit -m "Update standalone gh-pages build"

# Выгрузка только папки gh-pages в отдельную ветку gh-pages на GitHub
git subtree push --prefix gh-pages origin gh-pages
```

## ⚙️ Включение GitHub Pages в панели GitHub

1. Откройте ваш репозиторий на сайте GitHub: `https://github.com/<username>/<repo>`.
2. Перейдите в **Settings** (Настройки) → слева вкладка **Pages**.
3. В разделе **Build and deployment**:
   - **Source**: выберите `Deploy from a branch`.
   - **Branch**: выберите `main` (или `gh-pages`), папку `/ (root)` и нажмите **Save**.
4. Через 30–60 секунд страница станет доступна по адресу:
   ```text
   https://<ваш-логин>.github.io/<имя-репозитория>/
   ```

Нажмите на странице кнопку **«Открыть чат на сайте»** или **«Написать в виджет ↘»** — виджет раскроется и сразу начнет полноценный диалог!
